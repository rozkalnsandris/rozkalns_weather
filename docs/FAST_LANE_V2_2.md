# FAST-LANE v2.2

For ordinary Weather repository work:

1. refresh current GitHub state;
2. make safe source/docs/tests changes;
3. create/update a focused PR;
4. run CI and fix scope-preserving failures;
5. stop at Ready.

MERGE always requires an explicit owner command.
LIVE/data/secret/host mutation is never implied by source work or merge.

The shared policy source remains `rozkalnsandris/ops-workflows`. This local file intentionally contains only the Weather-specific operating summary.
